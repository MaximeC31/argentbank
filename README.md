# Argent Bank

Application bancaire en React et Redux permettant la connexion et la modification du profil via une API authentifiée par JWT.

## 🚀 Comment démarrer

### Prérequis

-   Node.js (version 18 ou supérieure)
-   npm ou yarn
-   MongoDB (local ou cloud)

### Installation du projet complet

1. **Cloner le dépôt**

    ```bash
    git clone https://github.com/MaximeC31/argentbank.git
    cd argentbank
    ```

2. **Installer les dépendances du frontend**

    ```bash
    npm install
    ```

3. **Installer les dépendances du backend**
    ```bash
    cd backend
    npm install
    cd ..
    ```

### Lancement du backend

```bash
cd backend
npm run dev:server
```

Le serveur backend démarrera sur `http://localhost:3001`

### Lancement du frontend

Dans un nouveau terminal, à la racine du projet :

```bash
npm run dev
```

L'application frontend sera disponible sur `http://localhost:5173/argentbank/`
